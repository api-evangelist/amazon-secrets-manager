This post introduces network firewall rules based on Kubernetes attributes rather than ephemeral IP addresses, for containerized workloads on Amazon EKS and ECS. It automatically tracks pod lifecycle events, updates IP mappings dynamically, and provides enriched logging tracing traffic to originating workloads.
